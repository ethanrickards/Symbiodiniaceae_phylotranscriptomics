**Orthofinder**

Finds orthologous proteins and generates orthogroups to create phylogenies. We use the MSA option Orthofinder to automatically generate a maximum likelihood tree based on multiple sequence alignment. This option requires fasttree in order to properly work. Your peptides folder should include references as well.  I recommend having your references across multiple clades of Symbiodiniaceae!

```
/path/to/Orthofinder -f /path/to/peptides -M msa -o /path/to/desired/output_directory
```

This study uses a mixture of slurm and python for all computing, you may have to increase the file descriptor limit.

```
ulimit -n 4096
```

Go to your Orthofinder results and the contained SpeciesTree folder. The SpeciesTree folder contains an _automatically generated_ maximum likelihood  species tree using msa.  The Orthogroups used are located in the generated "Orthogroups_for_concatenated_alignment" text file

View the tree however you wish, we used figtree to visualize the given tree file.

Create a new folder for single copy genes

There is a Single_Copy_Orthologue_Sequences folder that contains all orthogroups where every sample has one sequence.  Orthogroups_SingleCopyOrthologues.txt lists the name of each of these Orthogroups.
Direct to the Single_Copy_Orthologue_Sequences folder.

create the following folders:

```
mkdir Renamed_Orthogroups transcripts blast_results Orthogroups_for_Concatenation
```

We have a series of programs to re-QC the protein sequences. This is largely a sanity check, as most of the time the QC will have no effect on the dataset.  If you so wish, you can repeat this process for the dataset of the tree generated by Orthofinder, the "Orthogroups_for_concatenated_alignment" file. As those sequences are _not_ single copy, concatenation is a little more difficult.  We found that using the longest sequence with the highest %id when blasting against reference genomes was the best.

We will use the orthogroups, find their associated transcripts pre-TransDecoder, and blast them against reference genomes. We will then remove any problematic Orthogroups prior to concatenation and creation of a phylotranscriptomic trees.  At this point, we should NOT have non-Symbiodiniaceae sequences present in our samples!

Run
```
for file in *.fa; do
  basename="${file%.fa}"
  python rename_sequences.py "$file" "Renamed_Orthogroups/${basename}_renamed.fa"
done
```

Adjust the rename_sequences.py to format to your sequence naming conventions! It is vital that your sequence names directly match!
Next, we want to find the associated transcript. direct to the Renamed_Orthogroups folder

```
for file in *.fa; do
  basename="${file%.fa}"
  python extract_sequences.py "$file" /location/of/Separated/Transcripts ../transcripts/${basename}_transcript.fa
```
Now we blast these against reference databases. For this, use trusted reference transcriptomes or genomes. At this point, you should know which clade your Symbiodiniaceae samples belong to. If you are unsure, check the automatically-generated Orthofinder tree.

For blasting, you can either run for each Symbiodiniaceae reference or concatenate and make a single large database. While not the most refined, the latter method worked well.

```
python Orthogroup_Blast.py . /location/of/concatenated/reference/database ../blast_results/ 80
```

You will have a large .tsv file showing the number of total matches and the number of unique matches. You will need to parse through this file. As these are all single-copy, you should see the number of total matches equal the number of samples you have. Unique matches are important in indicating how your gene is represented in the genome, and overall quality of the Orthogroup.  For this, remove orthogroups whose number of total matches does not equal the number of samples you have, or orthogroups who have a very high number of unique matches (we used 50 as the benchmark). If you are running QC on non-single copy orthogroups, the number of total matches should have at least 80% of your total sample count.
IF you find most of your Orthogroups are low-quality, revist QC prior to performing transdecoder. Consider running blast of the whole transcriptome against the reference transcriptome/genomes, with an e-value target of 1e-10.  
Create a text file (Orthgroups_for_Concatenation.txt) containing the names of each Orthogroup that passed QC.
We will then move these Orthogroups into the Orthogroups_for_concatenated_alignment folder.

```
awk '{print "cp Single_Copy_Orthologue_Sequences/"$1".fa Orthogroups_for_Concatenation/"}' Orthogroups_for_Concatenation.txt | bash
```
Next, we will concatenate!  We need to make sure that sequences are all identically named for concatenation. We will remove sequence identifiers (such as tr number).  The resulting sequences will look like

">SAMPLENAME1"

">SAMPLENAME2"

etc.  IF you are running non-single copy sequences and not every sample is represented, you may need to add the missing sequence headers.

mkdir Renamed alignments

```
for f in *.fa; do
    base="${f%.fa}"
    awk '
        /^>/ {
            split($0, a, "_")
            print a[1]
            next
        }
        { print }
    ' "$f" > "${base}_Species_only.fa"
    echo "Processed: $f -> ${base}_Species_only.fa"
done
```

Move these to the Renamed file and then move into that file. We will then align each of the Orthogroups.

```
for file in *.fa; do
	basename=$(basename "$file" .fa)
	mafft "$file" > "../alignments/${basename}_aligned.fa"
done
```

After this, we will concatenate ALL of our sequences using AMAS. 

```
python3 AMAS.py concat -f fasta -d dna -i *.fa -t concatenated_SingleCopy.fa -u fasta
```

Then, create a sequence tree of the samples! This will take a while.

```
iqtree2 -s concatenated_SingleCopy_orthogroups.fa -m MFP -bb 10000 -nt 32
```

Congratulations! You now have a species tree of Symbiodiniaceae.
