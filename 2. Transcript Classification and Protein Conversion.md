**Classification of Transcripts**

Separation of Symbiodiniaceae from host sea anemone transcripts via Kraken2.  In order to do this, use reference transcriptomes of Symbiodiniaceae and host species.  
For this study, we used the following transcriptomes for Symbiodiniaceae:

```
Breviolum pseudominutum - Parkinson et al. 2016, http://zoox.reefgenomics.org/download/
Durusdinium trenchii - Chen et al. 2023, https://espace.library.uq.edu.au/view/UQ:2692e99
Cladocopium goreauii - Shoguchi et al. 2018, https://marinegenomics.oist.jp/symb/viewer/download?project_id=40
Symbiodinium microadriaticum - Aranda et al. 2016, http://smic.reefgenomics.org/
``` 

The use of additional transcriptomes of both host and dinoflagellate may influence separation.  These four transcriptomes, along with seven transcriptomes of host anemones, provided a clean separation between anemone and Symbiodiniaceae transcripts. These transcriptomes were concatenated, then created into a blast database.
We use a series of filtering steps through BLASTn to cleanly separate between the two transcriptomes. We had previously used Kraken2 to separate transcripts with moderate success, though this separation was not as clear as using Blast. 

For this, we used BLASTn against high-quality reference transcriptome databases belonging to both Symbiodiniaceae and Giant Sea Anemone. Only sequences that match either host or symbiont transcripts are kept, transcripts that match to none or both are discarded.

```
NDIR="/path/to/assembled/sequences"
SYMDB="/path/to/Symbiodiniaceae/blast/db"
CNIDDB="/path/to/Anemone/blast/db"

mkdir -p blast_sym blast_cnid filtered_sym filtered_cnid ambiguous unknown

for fasta in "$INDIR"/*.fasta.mod02; do

    [ -e "$fasta" ] || { echo "No .fasta.mod02 files found."; exit 1; }

    base=$(basename "$fasta" .fasta.mod02)

    echo "Processing $base"

    blastn \
        -query "$fasta" \
        -db "$SYMDB"/Symbiodiniaceae_Concatenated_db \
        -outfmt "6 qseqid" \
        -evalue 1e-10 \
        -max_target_seqs 1 \
        -num_threads 8 > blast_sym/${base}.txt

    blastn \
        -query "$fasta" \
        -db "$CNIDDB"/Anemone_Concatenated_db \
        -outfmt "6 qseqid" \
        -evalue 1e-10 \
        -max_target_seqs 1 \
        -num_threads 8 > blast_cnid/${base}.txt

    awk '
    FNR==NR {sym[$1]=1; next}
    FILENAME==ARGV[2] {cnid[$1]=1; next}

    /^>/{
        id=substr($1,2)

        if(id in sym && !(id in cnid))
            out="'filtered_sym/${base}_SYM.fasta'"

        else if(id in cnid && !(id in sym))
            out="'filtered_cnid/${base}_CNID.fasta'"

        else if(id in sym && id in cnid)
            out="'ambiguous/${base}.fasta'"

        else
            out="'unknown/${base}.fasta'"
    }

    {print >> out}

    ' blast_sym/${base}.txt blast_cnid/${base}.txt "$fasta"

done
```
Keep only those in blast_sym or blast_cnid.


**Peptide Prediction**

Use Transdecoder to convert transcripts to peptide for Orthofinder.  also include references you wish to use as outgroups/comparisons in this step.  We used transcriptomes belonging to those above, along with an outgroup of _Prorocentrum cordatum_, from Chen et al. 2023, https://espace.library.uq.edu.au/view/UQ:2692e99

We use the option of --single_best_only to keep the best ORF per transcript. Sometimes, this can be referred to as --single_best_orf instead.

```

for file in /location/of/filtered/Kraken_Outputs/*_filtered.fasta; do
	TransDecoder.LongOrfs -t "$file"

	TransDecoder.Predict -t "$file" --single_best_only
done
```
This should output .pep files for use in orthofinder.

**Cleaning Peptides**

Clean and remove redundant peptides through cdhit

```
for pep in "/path/to/Transdecoder/output/*.pep; do
    base_name=$(basename "$pep_file" .pep)

    cd-hit -i "$pep" -o "${base_name}_cdhit95.pep" -c 0.95 -n 5 -M 16000 -d 50 -T 4
done

```
