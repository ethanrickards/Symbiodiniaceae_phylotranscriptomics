**Orthofinder**

Finds orthologous proteins and generates orthogroups to create phylogenies. We use the MSA option Orthofinder to automatically generate a maximum likelihood tree based on multiple sequence alignment. This option requires fasttree in order to properly work. Your peptides folder should include references as well.  I recommend having your references across multiple clades of Symbiodiniaceae!

```
/path/to/Orthofinder -f /path/to/peptides -M msa -o /path/to/desired/output_directory
```

This study uses a mixture of slurm and python for all computing, you may have to increase the file descriptor limit with ulimit.

Go to your Orthofinder results and the contained SpeciesTree folder. The SpeciesTree folder contains an _automatically generated_ maximum likelihood  species tree using msa.  The Orthogroups used are located in the generated "Orthogroups_for_concatenated_alignment" text file.  Note that this species tree does not have bootstrap values. Luckily, the alignment is located in the folder "MultipleSequenceAlignments" as SpeciesTreeAlignment.fasta.  Use that to create a tree with supports.

```
iqtree2 -s SpeciesTreeAlignment.fa -m MFP -bb 10000 -alrt 2000 -nt 32
```

View the tree using whatever program you would like, we used figtree to visualize the given tree file.

There is a Single_Copy_Orthologue_Sequences folder that contains all orthogroups where every sample has one sequence.  Orthogroups_SingleCopyOrthologues.txt lists the name of each of these Orthogroups.
Direct to the Single_Copy_Orthologue_Sequences folder.

create the following folders:

```
mkdir alignments Species_Only
```
These should only contain one sequence per sample, with all samples present. Since the goal is to concatenate, you need to have consistent species headers names.
```
for f in *.fa; do
    base="${f%.fa}"
    awk '
        /^>/ {
            split($0, a, "_")
            print a[1]
            next
        }
        { print }
    ' "$f" > "${base}_Species_only.fa"
    echo "Processed: $f -> ${base}_Species_only.fa"
done
```

Move these to the Renamed file and then move into that file. We will then align each of the Orthogroups.

```
for file in *.fa; do
	basename=$(basename "$file" .fa)
	mafft "$file" > "../alignments/${basename}_aligned.fa"
done
```

After this, we will concatenate ALL of our sequences using AMAS. AMAS is accessible from https://github.com/marekborowiec/AMAS  

```
python3 AMAS.py concat -f fasta -d dna -i *.fa -t concatenated_SingleCopy.fa -u fasta
```

Then, create a sequence tree of the samples. This will take a while.

```
iqtree2 -s concatenated_SingleCopy_orthogroups.fa -m MFP -bb 10000 -nt 32
```

Congratulations! You now have species trees of Symbiodiniaceae.
